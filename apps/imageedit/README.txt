==========================================

現在の共通assets版: v2.3.0。アプリ固有版は v1.12.3 です（Issue #203、未リリース）。
今回更新したimage.jsのキャッシュ識別子は1.12.3です。未変更のimage.cssは1.12.2を維持します。
未変更のeditor-actions.jsは1.10.0、annotation-style.jsは1.8.0を維持します。

■ 1. 概要


JPEG、PNG、WebP画像をブラウザ内で加工するための庁内向けツールです。

「1枚ずつ加工」モードでは、トリミング、リサイズ、回転、反転、
黒塗り、モザイク、文字・図形による注釈、形式変換および容量調整を
行えます。

黒塗り、モザイク、文字、四角形、円、矢印、追加画像は編集可能なレイヤーとして
管理されます。保存前であれば、加工箇所の移動、サイズ変更、
順序変更、設定変更および削除ができます。

「複数画像を一括処理」モードでは、複数画像へ共通のリサイズ、回転、
形式変換、容量調整、文字透かしおよびファイル名変更を適用し、
処理後の画像と処理結果CSVをZIPファイルとして保存できます。

読み込んだ画像はクライアント端末のブラウザ内で処理されます。
本ツールには、画像をサーバーまたは外部サービスへ送信する処理は
ありません。


■ 2. 動作環境


サーバー:
- Windows Server
- IIS

クライアント:
- Microsoft Edge

画像の処理性能、読込み可能形式および保存可能形式は、
Microsoft EdgeのCanvas機能、画像デコーダー、画像エンコーダー、
端末のメモリ容量等に依存します。

WebP等の選択形式へ正しく変換できなかった場合は、
異なる拡張子で保存せず、エラーを表示します。


■ 3. 構成ファイル


- index.html: 画像加工画面
- image.css: アプリ固有のスタイル
- image.js: 画像読込み、加工、出力処理
- drawing-core.js: 図形の制約、端点編集、手書きの座標計算
- annotation-style.js: 文字書式、折返し、白縁取りのCanvas描画
- stamp.js: スタンプの描画・日付・テンプレート検証
- editor-actions.js: 操作メニュー・スタンプダイアログ
- help.html: 利用者向けヘルプ
- ../../assets/: AppBox共通のスタイル

使用しません。CSSおよびJavaScriptは、同一サーバー上のファイルを

index.htmlが読み込む共通ファイル:

- ../../assets/appbox-themes.css
- ../../assets/appbox-base.css

- ../../assets/appbox-icons.css

help.htmlが読み込む共通ファイル:
本体のimage.cssには依存しません。

- ../../assets/appbox-tokens.css
- ../../assets/appbox-themes.css
- ../../assets/appbox-base.css
- ../../assets/appbox-chrome.css
- ../../assets/appbox-help.css
- ../../assets/appbox-help.js

重要:
「../../assets/」は共創アプリBOX共通のアセットです。
appbox\assets\を同時に配置しないと表示が崩れます。
本ツールだけを単独で切り出して配置することはできません。
詳細はappbox\assets\README.txtを参照してください。

操作アイコンは ../../assets/appbox-icons.css と appbox-icons.svg に依存します。
共通assets v2.3.0を同時に配置し、SVGが image/svg+xml で返ることを確認してください。
ボタンの日本語ラベル・操作は維持し、図柄の正本は共通SVGで管理します。

共通CSSは必ずimage.cssより前に読み込みます。
共通CSSはCSSカスケードレイヤー（@layer appbox）を使用しており、
レイヤーに属さないimage.cssが常に優先されます。
そのため共通CSSを追加しても既存画面の見た目は変わりません。

利用者向けの説明はhelp.htmlです。
README.txtは管理者・保守担当者向け資料であり、
一般利用者向けのリンク先には使用しません。


■ 5. 主な機能と仕様


● 対応画像形式

読込み:
- JPEG（.jpg / .jpeg）
- PNG（.png）
- WebP（.webp）

保存:
- JPEG
- PNG
- WebP

一括処理:
- 元画像と同じ形式
- JPEGへ統一
- PNGへ統一
- WebPへ統一

非対応:
- HEIC / HEIF
- GIF
- BMP
- TIFF
- SVG
- RAW画像
- アニメーション画像

注意:
拡張子が対応形式でも、ファイルが破損している場合や、実際の内容が
対応画像ではない場合は読み込めません。
読込みは1ファイル25MiB以下・各辺8,192px以下・3,600万画素以下（一括時は合計150MiB・30枚）。
画像ヘッダーの実体をデコード前に確認し、実際の展開サイズとの不一致も拒否します。
JPEGのEXIF・PNGのeXIfによる縦横の入替えを考慮して照合します。

● 1枚ずつ加工モード

画像の読込みに成功すると、アプリ名・導入説明の表示を省いて作業領域を広げます。
「画像を変更」、元に戻す、やり直す、「すべて戻す」、「比較」、「保存」は共通ヘッダーへまとめます。
未読込み時と一括処理タブでは導入説明を表示し、単体編集用のヘッダー操作は表示しません。
読込みの失敗・取消では以前の表示状態を保ち、画面の切替は画像寸法や加工履歴に影響しません。
単体・一括とも画像の読込み後は加工方法のタブを隠します。ヘッダーの「加工方法を変更」で
タブを再表示でき、加工方法を切り替えて戻っても画像・編集内容・履歴を保持します。
狭い画面・低い画面でも必要な操作へスクロールしてアクセスできます。

次の加工・操作を行えます。

操作:
- 選択
- 手のひら

マスキング:
- 黒塗り範囲
- モザイク範囲
- 黒塗りブラシ
- モザイクブラシ
- ブラシ幅の変更
- モザイクサイズの変更

文字・図形:
- 文字
- 四角形
- 円
- 矢印
- 注釈色の変更
- 文字サイズの変更
- 線幅の変更
- 透過PNG等の画像をレイヤーとして追加
- 追加画像の透明度変更

画像操作:
- 自由範囲のトリミング
- 指定比率によるトリミング
- トリミング範囲の数値指定
- 左90度回転
- 右90度回転
- 左右反転
- 上下反転
- ピクセル数を指定したリサイズ
- 縦横比を維持したリサイズ
- 表示倍率の変更、全体表示、100%表示
- 手のひらツールおよびスクロールバーによる表示範囲の移動

出力:
- JPEG、PNG、WebPへの形式変換
- 標準の保存形式はPNG。単体処理のJPEGは透明部分を白背景で合成
- 目標容量に合わせた自動調整
- 保存ファイル名の変更
- 保存ダイアログ内で用途別の出力条件を選択

確認・履歴:
- 読込み時と現在の加工結果の比較プレビュー
- 画像上で選択し、Delete／Backspaceまたは右クリック／長押しメニューで削除。重なり順は右側のボタンからも操作
- 元に戻す
- やり直す
- 読込み時の状態へ戻す

● 編集可能レイヤー

次の加工は、保存するまで編集可能なレイヤーとして管理されます。

- 黒塗り範囲
- モザイク範囲
- 黒塗りブラシ
- モザイクブラシ
- 文字
- 四角形
- 円
- 矢印
- 追加画像（透明部分を保持）

レイヤーに対して行える操作:
- 画像上で選択
- 選択ツールで空白から矩形ドラッグし、範囲と交差する複数の表示中レイヤーを選択
- Shiftを押しながらクリックして選択を追加・解除、Shiftを押しながら矩形ドラッグして追加
- ドラッグによる移動
- 複数選択した対象を相対位置を保ってまとめて移動・削除・コピー・貼り付け
- 単一選択時、選択枠右下のハンドルによるサイズ変更
- 加工設定の変更
- 右側のボタン・右クリックメニューによる最前面・最背面への順序変更
- 個別削除
- 配置済み文字のダブルクリックによる画像上での内容編集
- Delete / Backspaceによる選択レイヤーの削除
- Ctrl+C / Ctrl+V（macOSはCommand）による選択レイヤーのコピー・貼り付け

選択したレイヤーに応じた設定だけを表示し、変更を直接反映します。
複数選択中は、各設定を適用できる対象へまとめて反映します。文字内容は画像上で1件ずつ編集します。
異なる設定が混在する項目は空欄・チェックの中間状態・色欄の枠で示します。
選択ツールで対象がないときは設定項目を隠します。右ペインの幅は確保し、画像位置を保ちます。
ツールは左サイドに2列で常時表示し、大きな画面ではウィンドウ幅を使って編集領域を広げます。
「選択」は、配置済みオブジェクトの選択・移動・サイズ変更・再編集に使います。
入力欄、文字編集中、IME変換中、ダイアログ内では通常の文字操作を優先します。
コピーしたレイヤーの貼り付けは、内容・書式を保持した別のレイヤーを作成します。

● 右側の設定欄

加工ツールは左、編集画像は中央、選択中の設定は右ペインへ配置します。
ツールと設定はそれぞれ縦スクロールでき、Tab移動でも各項目へ到達できます。
右側には文字・図形・トリミング等、選択対象に必要な項目だけを表示します。
トリミングは「回転・リサイズ」内の「リサイズ」の直前です。
文字色は「テキスト」、図形の線の色は「枠」、手書きや種類の混在時は「色」です。
文字と図形の塗り色は「塗り」、透明にする操作は「塗りなし」です。
文字と図形を一緒に選択した場合は「文字の塗り」「図形の塗り」を分けて表示します。
線の幅は「太さ」、文字サイズは「サイズ」で指定します。
文字設定はフォント・サイズ・文字色と太字・塗り・白縁、図形設定は枠色と太さ・塗り・白縁の順に表示します。
「サイズ」の−／＋で2pxずつ変更でき、数値入力は8〜300pxです。複数選択の文字は各サイズを相対変更し、ボタン1回ごとにUndoできます。
新規文字ツールでは次に配置するサイズを変更します。文字枠は画像上のハンドルでサイズを調整します。
選択中は右パネル下部の「最前面」「最背面」で重なり順を操作できます。
左右のペインは画像領域の高さに合わせ、狭い画面ではツールを画像の上、設定を画像の下へ配置します。
画像下部に画像寸法・表示倍率・「全体」「幅に合わせる」「100%」をまとめます。

● 画像の貼り付け

クリップボードに画像が含まれる場合は画像を優先して取り込みます。
ベース画像未読込み時はベース画像として、読込み済みなら画像レイヤーとして追加します。
編集中に貼り付けた画像は原寸のまま中央へ配置し、画像領域より大きい場合は横幅・高さをそれぞれ必要な分だけ広げます。
既存画像・レイヤーの位置や大きさは変えず、右側・下側に増えた余白は透明です。
拡張と画像追加は「元に戻す」1回で戻せます。比較・初期化に使う読込み時の画像は変更しません。
拡張後の辺長・総画素数が上限を超える場合は、画像を縮小せず貼り付けを取り消します。
ファイル選択の「画像を追加」は従来どおり画像領域へ収まる大きさで配置します。
非対応データのみの貼り付けでは画像を追加しません。

保存時は、表示中のレイヤーだけを画像へ焼き込みます。
非表示のレイヤーは保存画像へ反映されません。

注意:
レイヤーは本ツール内だけの編集情報です。
保存したJPEG、PNGまたはWebPに、編集可能なレイヤー情報は残りません。

● レイヤーの描画仕様

元画像、確定済み加工レイヤー、選択枠等の操作表示は、
それぞれ別のCanvasで管理します。

- 元画像用Canvas
- 加工レイヤー用Canvas
- 選択枠・トリミング枠・作成中プレビュー用Canvas

この構成により、モザイクブラシ等の追加時に、それ以前の黒塗り、
注釈または他のモザイクが消えないようにしています。

モザイクは元画像と、その下にある表示中のレイヤーを合成して生成します。
追加画像や注釈にも加工でき、レイヤーの設定・表示・上下順序を変更すると
素材を更新します。モザイクより上のレイヤーは加工対象に含みません。
加工範囲内は白背景と合成してからモザイク化し、元の細部が透けることを防ぎます。
範囲外の透明度は変更しません。
モザイク素材のキャッシュ件数を制限し、粗さを変更し続けても画像を蓄積しません。

位置・サイズは画像のピクセル座標で保持し、表示倍率とは独立して管理します。
元画像・レイヤー・操作表示の三枚のCanvasは、同じ親要素の表示寸法を使用します。
ウィンドウ幅やページ倍率の変更時は表示寸法だけを再計算します。

● 表示ズーム

画像下部の「表示倍率」で縮小・拡大・「全体」・「幅に合わせる」・「100%」を選べます。
画像の作業領域では、ホイールを上へ回すと拡大、下へ回すと縮小します。Ctrl / Commandは不要です。
ポインターの位置を中心に倍率を変更し、領域外では通常のページスクロールを使えます。
文字入力欄・設定フォーム上や、描画・IME変換・処理・手のひら移動の途中では従来の操作を優先します。
拡大中は「手のひら」で画像をドラッグするか、スクロールバーで表示範囲を移動します。
表示ズームは編集用の表示だけを変更し、保存寸法、レイヤー座標、Undo / Redoへ影響しません。
保存する画像の寸法変更には「リサイズ」、出力だけの寸法指定には保存時の用途設定を使います。

● トリミング

トリミングツールを選択した直後は枠を表示せず、画像全体を半透明の黒で薄く暗転します。
範囲を指定すると枠の内側は明るく、外側だけを暗く表示します。
キャンセルや別ツールへの切替で暗転を解除します。暗転は表示用で、元画像・保存画像・履歴を変えません。
画像上のドラッグで位置と範囲を指定し、右側の設定欄で横幅・高さと比率を調整します。

トリミング枠の操作:
- 枠の内側をドラッグして移動
- 四隅のハンドルをドラッグしてサイズ変更
- 枠外からドラッグして新しい枠を作成
- 横幅・高さを数値で指定（既存の枠の位置を維持し、未指定時は画像左上を基準に作成）
- 「中央配置」で枠を画像の中央へ移動
- 「キャンセル」で選択ツールへ戻る

操作は右側の設定欄にまとめています。
範囲が決まったら「この範囲で切り抜く」で確定します。範囲未指定の間は確定できません。

トリミング確定後は、元画像と各加工レイヤーの座標および範囲を
新しい画像サイズに合わせて調整します。
四角形の枠線や円は形状を維持し、画像に残る部分だけを表示します。

トリミング枠自体は一時的な操作情報であり、通常の加工レイヤーとしては
保存しません。

● トリミング比率

次の比率を選択できます。

- 自由
- 1:1
- 4:3
- 16:9
- 3:4
- 35:45
- 読込み時の元画像比率

注意:
証明写真の寸法、比率、画素数、背景、顔の位置等の要件は、
手続きや提出先によって異なります。

本ツールの比率選択肢は作業補助のための例であり、
提出要件への適合を保証するものではありません。
必ず提出先の規定を確認してください。

● モザイクおよび黒塗り

範囲ツール:
画像上の対象範囲をドラッグし、長方形の加工レイヤーを作成します。

ブラシツール:
画像上を自由になぞり、ストローク単位の加工レイヤーを作成します。

モザイク:
- 指定したブロックサイズで画像を粗く表示します。
- ブロックサイズは保存前に変更できます。
- 元画像と下位の表示中レイヤーを基にモザイク画像を生成します。

黒塗り:
- 指定範囲またはブラシの軌跡を黒色で塗りつぶします。
- 保存画像へ黒色のピクセルとして焼き込まれます。

注意:
保存前および保存後に画像を目視確認し、個人情報、車両番号、
文書内容等が確実に判別できない状態になっていることを確認してください。

モザイクは対象や設定によって元の内容を推測できる場合があります。
確実な秘匿が必要な箇所には、対象より十分に広い範囲を黒塗りすることを
推奨します。

● 文字・図形

次の注釈を追加できます。

- 文字
- 四角形
- 円
- 矢印
- 直線
- カラー手書き
- 画像として配置する定型・日付スタンプ

設定可能な項目:
- 文字内容（画像上で直接編集）
- テキスト・枠・手書きの色
- 文字サイズ（数値入力と−／＋ボタン）
- 線の太さ
- フォント（端末内12種類、選択中のプレビュー）・太字
- 改行・文字枠幅による折り返し・文字の塗り色・塗りなし
- 文字、矢印、直線、四角形、円の白縁取り
- 四角形と円の塗り色・塗りなし

新規配置時の白縁取りは、文字・矢印・直線で有効、四角形・円で無効です。
変更した設定はツールごとに記憶し、次の配置に引き継ぎます。
文字・矢印・直線には厚めの白縁取りを付け、背景と区別しやすくしています。

文字ツールで配置すると空の文字枠で編集を開始します。右側の設定欄に文字内容の入力欄は置きません。
配置済み文字はダブルクリックで編集し、点滅するキャレットが入力位置を示します。
Enterで改行し、Ctrl+Enter（macOSはCommand+Enter）、Escまたは別の場所へのフォーカス移動で編集を終了します。
IME変換中のキー操作は文字入力を優先します。

四角形・円・矢印・直線は配置後に選択モードへ戻り、配置した図形を選択します。
続けてドラッグすると図形を移動でき、次の図形はツールを再度選んで配置します。

作図のキー操作:
- 四角形・円の配置時はCtrl / Shiftで正方形・真円へ固定（円は縦横を変えて楕円としても配置可能）
- 四角形・円のサイズ変更時はCtrl / Shiftで現在の縦横比を保持
- 黒塗りブラシ・モザイクブラシ・カラー手書きのサイズ変更時もCtrl / Shiftで現在の縦横比を保持
- 直線・矢印の配置時と端点変更時はCtrlで水平・垂直へ固定
- 直線・矢印の端点変更時はShiftで元の角度を維持

カラー手書きは、色・太さ・手ぶれ補正（なし・弱・中・強）を指定できます。
消しゴムは手書きの線を1本ずつ消去します。黒塗り・モザイクブラシは消去対象に含めません。
描画や消去の途中でEscを押すと取り消し、選択ツールへ戻ります。

スタンプは「確認」「承認」「済」「回覧」「至急」「受付」等と日付を配置できます。
幅・高さは40〜1,200pxの画像座標で指定し、日付は西暦・和暦で表記できます。
文字は3行まで、{date}を配置日の表記へ置換します。
設定はJSONテンプレートとして端末へ保存・読込みでき、Web Storageへは保存しません。
配置後は通常の画像レイヤーとして移動・比率固定リサイズ・不透明度・重なり順を変更できます。
スタンプ設定ダイアログは画面内に収め、見出し・閉じる操作を固定して本文内を縦スクロールできます。
狭い画面では1列に並べます。

追加した注釈は、保存前であれば移動、サイズ変更、設定変更、
順序変更および削除ができます。

● 比較プレビュー

「比較」ボタンを押すと、
次の画像を左右に並べて確認できます。

- 読込み時の元画像
- 現在の加工結果

現在の加工結果には、表示中のレイヤーを合成した状態が反映されます。

トリミング、回転またはリサイズを行った場合は、
元画像と現在画像で構図や寸法が異なることがあります。

個人情報等を秘匿する場合は、保存前に比較プレビューでも
加工漏れがないことを確認してください。

● 定型プリセット

単体処理および一括処理で、次のプリセットを選択できます。

- Web掲載用
- メール添付用
- 庁内文書貼付用
- サムネイル用
- 原寸・メタデータ除去

単体処理の用途はヘッダーの「保存」で開くダイアログ内で選びます。
用途は出力形式、長辺、目標容量等を設定し、保存時だけ出力画像へ適用します。
編集中の画像やレイヤーの寸法は変更しません。一括処理のプリセットは従来どおりです。

注意:
プリセットは一般的な作業を補助する初期値です。
掲載先、メール環境、文書システム等の個別要件への適合を
保証するものではありません。

● 画像サイズおよび容量の上限

ブラウザのメモリ枯渇や応答停止を防止するため、
次の上限を設けています。

1ファイル:
- 最大容量: 25MB
- 最大幅: 8,192px
- 最大高さ: 8,192px
- 最大総画素数: 36,000,000画素

一括処理:
- 最大枚数: 30枚
- 合計容量: 150MB
- 1ファイルの最大容量: 25MB
- 各画像の最大幅、高さおよび総画素数は単体処理と同じ

上限を超える画像は読み込まないか、一括追加時にスキップします。

上限以内であっても、画像の寸法、枚数、圧縮形式、加工レイヤー数、
端末性能等によっては処理に時間がかかる場合があります。

● リサイズ

1枚ずつ加工する場合は、横幅と高さをピクセル単位で指定できます。

「縦横比を維持」が有効な場合は、一方を変更すると、
もう一方を自動計算します。

一括処理では、次の方法を選択できます。

- 長辺を指定ピクセル以下にする
- 指定した最大横幅・最大高さの範囲内に収める
- 横幅を指定する
- 高さを指定する
- リサイズしない

「元画像より大きくしない」を有効にすると、
元画像より小さい指定でない限り拡大しません。

● 目標容量の自動調整

目標容量を有効にすると、指定容量以下になるよう画像を自動調整します。

JPEG / WebP:
- 画質を段階的に調整します。
- 最低画質でも目標容量を超える場合は、出力画像の寸法を縮小します。

PNG:
- 画質設定による調整は行いません。
- 目標容量を超える場合は、出力画像の寸法を縮小します。

最小出力寸法まで調整しても目標容量を達成できない場合は、
画像を保存した上で「目標容量未達」として警告します。

単体処理:
- 実際の出力容量
- 出力寸法
- 目標容量の達成または未達

を画面上に表示します。

一括処理:
- 画像一覧
- 最終集計
- 処理結果CSV

に目標容量未達を記録します。

注意:
目標容量は必ず達成できるものではありません。

● 一括処理

一括処理では、複数画像へ共通設定を適用し、
画像と処理結果CSVをZIPファイルとして保存します。

主な機能:
- 最大30枚まで追加
- 合計150MBまで追加
- 最大160pxの軽量サムネイルによる一覧表示
- 共通リサイズ
- 共通回転
- 共通形式変換
- 画像ごとの容量調整
- 文字透かし
- ファイル名の文字列置換
- 接頭辞および接尾辞の追加
- 連番名への置換
- ZIP名の変更
- 処理中止
- 最後に作成したZIPの再保存
- 処理結果CSVの出力

処理中は、画像の追加、削除、一覧消去、設定変更およびモード切替を
一時的に無効化します。

一括処理では、トリミング、モザイク、黒塗り、図形注釈等の
画像ごとの個別加工は行いません。
これらが必要な場合は「1枚ずつ加工」モードを使用してください。

● 一括文字透かし

一括処理では、各画像へ共通の文字透かしを追加できます。

設定項目:
- 透かし文字
- 配置位置
- 透明度
- 文字サイズ
- 色

配置位置:
- 左上
- 右上
- 左下
- 右下
- 中央
- 中央斜め

文字サイズは画像の短辺に対する割合で指定します。

透かしを無効にしている場合は、透かし文字、透明度および文字サイズは
処理条件として使用しません。

● 一括処理の中止

一括処理中は「処理を中止」ボタンを使用できます。

中止操作を行った場合、現在処理中の画像が完了した後に停止します。
処理中のエンコードを直ちに強制終了するものではありません。

中止前までに成功した画像と、全件の処理状況を記録したCSVは、
ZIPファイルとして保存します。

処理結果は次のいずれかで記録されます。

- 成功
- 成功（目標容量未達）
- 失敗
- 未処理

● ファイル名の取扱い

出力ファイル名には、Windowsで使用できない文字や、
パスとして解釈される文字を無害な文字へ置き換えます。

主な対象:
- バックスラッシュ
- スラッシュ
- コロン
- アスタリスク
- 疑問符
- ダブルクォート
- 山括弧
- 縦線
- 制御文字
- 連続するピリオド
- 末尾のピリオドおよび空白
- Windows予約名
  - CON
  - PRN
  - AUX
  - NUL
  - COM1～COM9
  - LPT1～LPT9

出力時にファイル名が変更される場合があります。

ZIP内で同じファイル名が重複した場合は、
「-2」「-3」等を付けて区別します。

● ZIPファイル

一括処理後の画像と処理結果CSVは、無圧縮ZIPとして保存します。

JPEG、PNG、WebPは既に圧縮された画像形式であるため、
ZIP内部での追加圧縮は行いません。

ZIP内のファイル名:
- UTF-8で保存
- ZIPのUTF-8フラグを設定
- Windowsで使用できない代表的な文字を置換
- パス区切り文字を置換
- 連続するピリオドを無害化
- Windows予約名を無害化
- 同名ファイルへ連番を付与
- ファイル名の長さを制限

ZIP作成中は、処理中のファイル名と進捗を画面に表示します。

注意:
ZIP生成では画像データをブラウザのメモリ上へ展開します。
画像枚数や容量、端末性能によっては処理に時間がかかる場合があります。


■ 6. データの取扱い


● 処理結果CSV

一括処理で作成するZIPには「処理結果.csv」を含めます。

記録項目:
- 元ファイル名
- 結果
- 出力ファイル名
- 出力幅
- 出力高さ
- 出力容量（byte）
- 目標容量達成
- エラー

CSVはUTF-8のBOM付きで生成します。

CSV数式として解釈される可能性がある先頭文字を含む値は、
表計算ソフトで数式として実行されにくいよう無害化します。

● メタデータ

画像の保存時には、現在の見た目をCanvasから新しい画像として書き出します。

このため、元画像に含まれていた次のようなメタデータは、
原則として保存画像へ引き継がれません。

- EXIF情報
- GPS位置情報
- 撮影日時
- 撮影機種
- カメラ設定
- 元画像に含まれていたサムネイル

注意:
「元画像のメタデータを引き継がない」ことを目的とした設計です。

ブラウザや画像形式によって、新しい画像の生成に必要な情報が
付加される可能性まで含めて、全種類のメタデータが存在しないことを
保証するものではありません。

庁外公開等の重要な用途では、保存後の画像について別の確認手段でも
メタデータを確認してください。


■ 7. セキュリティとプライバシー


本ツールの画像処理は、Microsoft Edgeのブラウザ内で行います。

- 画像をサーバーへアップロードしません。
- 画像を外部サービスへ送信しません。
- 外部APIへ画像を送信しません。
- クラウドへ自動保存しません。
- 画像データをWeb StorageやIndexedDBへ保存しません。
- 処理後の画像またはZIPは、利用者の操作により端末へダウンロードします。

ただし、ダウンロードしたファイル、ブラウザキャッシュ、OSの一時領域、
クリップボード等の取扱いは、端末およびブラウザの設定に従います。

個人情報または機密情報を含む画像は、所属組織の情報セキュリティポリシーと
データ取扱規程に従って使用してください。

■ 9. 既知の制約


- HEIC、HEIF、GIF、BMP、TIFF、SVG、RAW画像には対応していません。
- アニメーション画像には対応していません。
- 一括処理では個別のトリミング、モザイク、黒塗り、注釈はできません。
- ZIPは無圧縮方式です。
- 一括処理の中止は、現在処理中の画像が終了した後に行われます。
- 目標容量を必ず達成できるとは限りません。
- 証明写真の物理寸法またはDPIを保証するものではありません。
- 操作履歴はページを閉じると失われます。
- 保存画像には編集可能なレイヤー情報は残りません。
- モザイクは元画像と下位の表示中レイヤーを基に生成します。
- モザイク処理は対象情報の完全な秘匿を保証するものではありません。
- 画像の内容や端末性能によっては、上限以内でも処理に時間がかかります。
- ZIP生成時は、画像データをブラウザのメモリ上へ展開します。
- ブラウザが選択した出力形式に対応していない場合は保存できません。

- 成功が正しく記録される
- 成功・目標容量未達が正しく記録される
- 失敗が正しく記録される
- 未処理が正しく記録される

■ 14. 更新履歴


● 操作履歴

「元に戻す」と「やり直す」は、加工レイヤーの状態または画像本体の状態を
ブラウザのメモリ内へ保持して実現します。

画像本体を含む履歴の保持上限:
- 5,000,000画素以下: 最大8件
- 5,000,000画素超～10,000,000画素以下: 最大4件
- 10,000,000画素超～20,000,000画素以下: 最大2件
- 20,000,000画素超: 最大1件

レイヤーのみの履歴を含む全履歴:
- 最大40件

画像本体の履歴を上限により破棄するときは、それ以前のレイヤー履歴も破棄します。
画像とレイヤーが対応する連続した履歴だけを保持します。

画像本体を含む履歴の例:
- トリミング
- リサイズ
- 回転
- 反転
- 画像貼り付けによる画像領域の拡張
- 読込み時の状態へ戻す

レイヤーのみの履歴の例:
- 加工レイヤーの追加
- 移動
- サイズ変更
- 順序変更
- 設定変更
- 削除

トリミング確定前の枠は一時的な操作情報として扱い、
操作履歴には保存しません。

ページを閉じると操作履歴は失われます。
