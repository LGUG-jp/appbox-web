お役立ちアプリBOX / QRコード作成アプリ  v1.4.1
======================================
本ツールの機能版数は、AppBox全体および共通assetsの版数とは別に管理します。
AppBox全体の履歴は README.md / CHANGELOG.md、共通assetsの仕様は
assets/README.txt / docs/COMMON_ASSETS.md を参照してください。


■ 1. 概要

URL、メールアドレス、電話番号、任意のテキストからQRコードを作成する
ブラウザ完結型のWebアプリです。

入力内容と中央画像はブラウザ内で処理し、QRコード作成のために外部API、
外部クラウド、外部Webサービスへ送信しません。

v1.4.1では、画面を次の3領域へ整理しています。

1. 左側：QRコードを作る
2. 右側：プレビュー・保存
3. 下部：詳細カスタマイズ（任意）

通常利用は「用途を選ぶ → 内容を入力 → QRコードを作成 → 保存」で完結します。
詳細カスタマイズは常時表示ですが、通常は初期設定のままで利用できます。


■ 2. 動作環境

サーバー:
- Windows Server / IIS
- 静的ファイルとして配信

クライアント:
- Microsoft Edgeを主対象
- JavaScript、Canvas、SVG、Blob、Object URL、File API、Image APIを使用

本番配置前に、実際の庁内環境で使用するEdgeで確認してください。


■ 3. 構成ファイル

標準配置は apps/qrcode/ です。

- index.html                 本体画面

共通assets版はv1.4.1、QRコード作成アプリ版はv1.4.1です。


■ 4. 主な機能

● 用途選択

以下の4種類から1つを選択します。

- URL
- メール
- 電話
- テキスト

選択UIは丸いラジオボタンです。
SMS用途はv1.4.0で画面から廃止しています。

URL:
- http:// または https:// で始まることを確認
- 改行、タブ、全角スペース、主要な全角URL記号などを検査

メール:
- mailto: が未指定の場合は自動付与

電話:
- tel: が未指定の場合は自動付与

テキスト:
- 入力内容をそのままQRコード化


● プレビュー・保存

QRコード作成後は右側にプレビューを表示します。
作成後には「QRコードは読み取り確認をしてください！」を表示します。

保存ファイル名は、PNG / SVG保存ボタンの直前で指定します。

保存形式:
- PNG: Word、PowerPoint、Webページなどの普段使い向け
- SVG: 拡大・縮小に強く、印刷物や大きく配置する用途向け
  ただし、SVG非対応のソフトやシステムでは利用できない場合があります。

「QRコード化した内容を確認」の表示・コピーUIはv1.4.1で画面から削除しました。


● 詳細カスタマイズ

左右2カラムの下に、横幅いっぱいの独立エリアとして表示します。
折りたたみは使用しません。

設定項目:
- PNG最大画像サイズ
- 誤り訂正レベル
- QRコード本体色
- 背景色
- 背景透明
- 中央画像

通常は初期設定のままで利用できます。


● 背景透明

背景透明はトグル形式でON / OFFします。

- ONにすると、既存のQRコードプレビューへ即時反映
- OFFにすると、通常背景へ即時復帰
- QRコード未作成時は設定状態を次回作成時に反映
- PNG / SVGの保存にも同じ設定を使用
- プレビューでは透明部分を市松模様で表示

背景透明では、配置先の背景色によって読み取りやすさが変わります。
完成物で必ず読み取り確認してください。


● 中央画像

PNG / JPEG / WebP、最大5MBの画像をQRコード中央へ配置できます。
中央画像を有効にすると、誤り訂正レベルをHへ変更して固定します。

画像はブラウザ内で処理し、最大320pxへ縮小してPNG化したうえで合成します。


■ 5. バージョン管理

QRコード作成アプリはAppBox全体とは別に機能版数を持ちます。

v1.4.1:
- 用途選択を通常のラジオボタン表示へ変更
- 作成 / プレビュー保存 / 詳細カスタマイズの3領域へ再構成
- 詳細カスタマイズを常時表示へ変更
- 保存ファイル名を保存ボタン直前へ移動
- PNG / SVGの説明を用途ベースへ見直し
- 背景透明をトグル表示へ変更
- 背景透明のプレビュー即時反映を明確化
- 「QRコード化した内容を確認」を画面から削除

v1.4.0:
- 用途選択をURL / メール / 電話 / テキストの4種類へ整理
- SMS用途を画面から廃止
- 詳細カスタマイズを折りたたみに集約
- 背景透明のPNG / SVG保存に対応
- 読み取り確認の注意表示を追加


■ 6. セキュリティ・プライバシー

- 入力内容と中央画像はブラウザ内で処理
- 外部API、外部クラウド、外部CDNを使用しない
- Cookie、Web Storage、データベースを使用しない
- 保存したQRコードには入力情報そのものが含まれる

個人情報、非公開URL、認証情報、パスワードなどを安易にQRコード化しないでください。


■ 7. 確認項目

リリース前は少なくとも以下をMicrosoft Edgeで確認してください。

- 4種類のラジオボタンが1つだけ選択できる
- URL / メール / 電話 / テキストが正しくQRコード化される
- QRコード作成後に読み取り確認の注意が表示される
- 保存ファイル名がPNG / SVG保存ボタン直前に表示される
- PNG / SVGを保存できる
- 背景透明ON / OFFがプレビューへ即時反映される
- 透明PNG / SVGが正しく保存される
- 中央画像あり + 背景透明でも表示・保存できる
- スマートフォン幅でレイアウトが崩れない
