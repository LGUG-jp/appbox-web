相続関係図（ジェノグラム）作成ツール

人物と関係を登録して相続関係図を作り、保存・出力するまでを説明します。

Version 2.2.0
本ツールは法的な判断を行うものではありません

法定相続人や法定相続分を自動で確定する機能はありません。 代襲相続や数次相続の自動判定、戸籍情報との照合、 相続放棄の効力の確認も行いません。

各項目へ入力しただけで、相続人、代表相続人、納税義務者、 納税管理人として法的・行政的に確定するものではありません。 業務上の整理用の図として使用してください。

基本の使い方

  1. 作り始め方を選ぶ

    初回起動時は基本の3世代サンプルが表示されます。白紙から作る場合は「新規 / サンプル」→「空白から作成」、保存した図を再開する場合は「保存 / 復元」→「ファイルを読み込む」を選びます。

  2. 人物を追加し、情報を入力する

    「＋ 人物追加」を押し、配置プレビューを確認して作図面をクリックします。人物追加モードを終了してから人物をクリックすると、氏名・性別・続柄などを入力できます。必要に応じて「詳細モード」で住所や業務情報を入力します。

  3. 人物同士の関係を登録する

    「関係」メニューの夫婦・親1人・親2人を選び、案内に従って人物をクリックします。人物カードの［•••］から「親族を新規追加」「既存人物との関係」も利用できます。続柄の文字を入力するだけでは関係線は登録されません。

  4. 配置と内容を確認する

    「整列」メニューや手動操作で位置を整え、必要な図形・注釈を追加します。「図のチェック」も利用できますが、法的な相続人の判定には使えません。

  5. 編集用のJSONを保存し、必要な形式で出力する

    「保存 / 復元」→「保存」で編集用のJSONファイルを保存します。自動保存はありません。資料用には別途PNG・SVGへ出力するか、「印刷」から印刷します。画像や印刷物から編集内容を復元することはできません。

利用モードの切り替え

ツールバー左端の「簡易モード」「詳細モード」ボタンで利用モードを切り替えます。

簡易モード（初期状態）
幅 190 px × 高さ 60 px の固定寸法で、続柄・関係を太字で大きく、氏名と性別を補助的に表示します。続柄が空欄なら氏名が主表示になります。死亡した人物には半透明の×印が付きます。 画面表示を簡潔に保ち、作図作業に集中できます。
詳細モード（相続相談向け）
基本項目に加え、住所、生年月日、死亡年月日、相続放棄の確認状況、共有持分、代表相続人、納税義務者候補、納税管理人候補、管理用 ID を表示します。 未入力の項目を縮めた可変高さで表示し、上部ツールバーの「一括操作」メニューから、一括編集、関係一覧・解除、図のチェックを利用できます。

モードの切り替えは画面の表示状態を変更するだけです。 登録済みの人物データ、座標、詳細情報、Undo 履歴には変更を加えずに保持します。 モード情報は JSON 保存ファイルに含めません。 画像（PNG）出力、SVG 出力、印刷プレビューおよび実印刷には、現在の利用モードのカード表示が反映されます。 アプリ起動時は簡易モードになり、JSON 復元時は現在のモードを維持します。

人物の追加と編集

人物を追加するときは、上部ツールバーの「＋ 人物追加」を押します。 作図面上でポインターを動かすと、半透明の配置プレビューが表示されます。 空いている位置をクリックすると新しい人物が配置され、続けて別の位置をクリックして連続配置できます。 人物追加モード中は詳細パネルを表示せず、配置に集中できます。情報を編集するときは追加モードを終了してから人物をクリックします。 作図面の上部中央にはコンパクトな操作案内を表示します。関係作成では進行段階とエラー理由を表示し、登録完了の通知は自動で消えます。初回ヒントと操作案内は重ねて表示しません。 追加を終了する場合は、「＋ 人物追加」をもう一度押すか、別のツールを選ぶか、または Esc キーを押します。

作図面の上部には、初回起動時に「人物クリックで情報編集、親子追加は•••か右クリック」という簡潔な案内を表示します。 閉じるボタン（[×]）を押すと非表示になり、次回以降の表示を抑制します（ブラウザーの端末保存領域に記録され、図の保存データ（JSON）には含めません）。 作図面のクリック、人物や図形の選択、ツールの使用時にも自動的に隠れます。

人物カードを左クリックまたはタップすると、その人物が選択状態になり詳細パネルが開きます。左クリックではメニューは開きません。 人物を押した位置から 5 px 以上ドラッグすると、詳細パネルを閉じて移動します。移動後も選択は維持し、詳細パネルは通常の左クリックで再表示できます。タッチ操作にも対応しています。 右クリックや［•••］で人物メニューを開くときも、詳細パネルは閉じたままです。テキストや図形も、移動と右クリックでは詳細パネルを閉じます。 親族の追加や削除、既存人物との関係作成などは、人物カードを右クリックするか、カード右上の［•••］ボタンを押して人物メニューを開きます。右クリックと［•••］ボタンは同一のメニューを開きます。 カード右上の［•••］ボタンは作図用の補助表示であり、画像出力（PNG）、SVG 出力、印刷プレビューおよび実印刷からは自動的に除外されます。

人物を配置した直後は追加モードを続けるため、詳細パネルは開きません。「＋ 人物追加」をもう一度押すか Esc で追加を終了し、編集したい人物をクリックしてください。 氏名、性別、続柄などの入力値は、IME 確定時や選択変更時に自動で反映されます。 人物 ID は「P001」などの形式で自動採番されます。

人物メニューまたは詳細パネルの「人物を削除」から人物を削除できます。 確認ダイアログで「OK」を選ぶとメニューを閉じて人物を削除します。 「キャンセル」を選ぶと削除を中止し、人物メニューを開いたまま維持します。

簡易モードでは氏名、性別、手入力の続柄・関係、死亡状態、死亡年月日を編集できます。 詳細モードに切り替えると、住所、生年月日、相続放棄、共有持分、代表相続人、納税義務者候補、納税管理人候補などの相続相談用の情報も編集できます。 旧 JSON に含まれる備考は画面から編集できませんが、ファイルの読み込みおよび保存時に値を保持します。

死亡日が不明でも「死亡」にチェックを付けられます。チェックを外すと、死亡年月日と以前の死亡情報・補足も消去します。「元に戻す」で復元できます。 生年月日と死亡年月日はカレンダーから選べます。対応ブラウザーではキーボードでも入力でき、入力途中や不正な日付は反映しません。一括編集も同じ方式です。

旧 JSON の「不明」「確認中」などは「以前の死亡情報・補足」に表示します。日付を後から追加しても、その文字列を補足として保存します。 カードの続柄・氏名は長いと省略しますが、ポインターを重ねると全文を確認できます。続柄は手入力のほか、「一括操作 → 続柄を自動設定」で候補から設定できます。

関係の登録

登録方法

  • ツールバー関係メニュー: ツールバーの「関係」ボタンから「夫婦」「親1人」「親2人」を選択し、作図面上の人物を順にクリックして登録します。Esc キーまたは作図面上部の中止ボタンで終了します。
  • 人物メニュー: 人物カードの右クリックまたは右上の［•••］ボタンを押し、「親族を新規追加」（配偶者・親・子）または「既存人物との関係」を選びます。既存人物と結ぶ場合は、案内に従って相手をクリックします。Esc キーで中止できます。
  • 関係線の選択と解除: 図上の夫婦線や親子線にポインターを合わせると強調表示され、左クリックで選択できます。Delete または Backspace キーを押すと確認ダイアログが表示され、関連する親子関係の解除などの影響を確認したうえで、人物を残したまま関係を解除できます。関係線の右クリックによる解除メニューは提供していません。
  • 一括操作メニュー: ツールバーの「一括操作」から「一括編集」や「関係一覧・解除」を開き、一覧・表形式で関係の確認や解除を行えます。

関係の仕様

  • 親子関係は「1 人の親と子」または「2 人の親と子」で登録できます。
  • 2 人以上の親が登録された family は、配偶者・親ペアとして扱います。夫婦間は二重線で表示されます。
  • 現行のデータモデルでは、親2人を指定して子との関係を作成すると、2人の親の間に夫婦線（二重線）も併せて自動生成されます。
  • 夫婦線のない親2人の登録（Issue #258）は未実装です。
  • 続柄自動設定では、親ペアは「配偶者（要確認）」として提示します。夫婦線があっても婚姻状態を自動確定しません。
  • 一括編集の親 1・親 2・配偶者は「ID:氏名」のプルダウンで選択します。配偶者を選ぶと次の選択欄が表示され、複数人を指定できます。「未設定」で選択を解除できます。
  • 一括編集では、存在しない人物 ID、自分自身を親や配偶者に指定、 親 1 と親 2 に同じ ID、配偶者 ID の重複、親 ID と配偶者 ID の重複を 反映前にチェックします。

一括編集などのモーダル表示中は、背景ではなく表やモーダル内をスクロールします。 未反映の変更があるときに背景・閉じるボタン・Esc で一括編集を閉じようとすると、「反映して閉じる」「破棄して閉じる」「編集を続ける」を選べます。 入力エラーや反映確認の取消時は編集を続けられます。図に反映した後も、JSON ファイルへの保存は別途必要です。

複雑な関係を登録したとき

再婚、養子縁組、代襲相続、数次相続などでは、複数の family が作成される場合があります。 登録後は「図のチェック」と「関係一覧・解除」で内容を確認してください。

一括編集の「関係」タブを反映すると、関係データは表の内容を基準に作り直されます。 反映前に入力内容を確認してください。

続柄を自動設定

図に登録された関係から続柄の候補を算出します。 戸籍上の親族関係や法定相続人・相続分を確定するものではありません。 簡易モード・詳細モードのどちらでも利用できます。

  1. 図上で基準にする人物を1人選び、「一括操作 → 続柄を自動設定」を開きます。未選択の場合はダイアログ内で氏名・続柄・IDを検索して選べます。
  2. 全員の既存の続柄、候補、判定状態と理由を確認します。必要に応じて基準人物を変更し、候補を計算し直します。
  3. 反映する文字列を修正し、必要な人物にチェックを付けます。「候補あり」で既存値が空欄の人物だけ、最初から選択されます。全解除や空欄だけの選択もできます。
  4. 反映件数と既存値を置き換える件数を確認し、反映します。既存値の置換がある場合は追加の確認を行います。

対象は本人、親、子、祖父母、孫、きょうだい、おじ・おば、甥・姪です。 性別未設定の場合は「親」「子」「祖父母」「親のきょうだい」「きょうだいの子」などを使います。 共有する親が1人でも「きょうだい」の候補を示しますが、全血・半血は区別しません。 長男・次男、兄・弟、姉・妹、伯父・叔父などの出生順や年齢順は推測しません。

候補あり
登録された親子関係から1種類の候補が得られました。既存の続柄がある行は初期選択しません。
要確認
「配偶者（要確認）」など、現行データだけでは確定できません。婚姻中・離婚・内縁は区別しません。確認して個別に選択してください。
複数候補
別種の続柄に当たる経路があります。候補を選ぶか文字列を修正してから、反映対象にしてください。
矛盾
親子の循環や不正な参照などがあります。自動候補は反映できません。図の関係を修正するか、続柄を手動指定してください。
判定不可
未接続や対象外の関係などです。理由を確認し、必要なら続柄を手動指定してください。

手動修正・手動指定は自動判定の成功とは別に表示します。 空値での一括消去は行わず、同じ文字列への変更は件数に含めません。 基準人物を変えるときや閉じるとき、変更した下書きがあれば破棄を確認します。 キャンセルでは図を変更せず、反映した変更全体は「元に戻す」1回で戻せます。「やり直し」も1回です。

保存するのは反映済みの続柄だけです。基準人物、候補、根拠、下書きは保存しません。 JSON形式は従来どおりで、反映後の続柄は通常の手入力でも編集できます。 印刷・SVG・PNGには、候補ではなく図に反映済みの続柄を表示します。 継親や連れ子など、登録のない親子関係は補いません。

選択パネルと複数選択

人物や図形を選んでいないときは、作図面を広く使えます。人物を探すときは上部の検索欄を使ってください。

作図面上の人物または図形を選択すると、広い画面では作図面の左側に詳細パネルが重なって開きます。 ただし人物追加モード中や移動中・移動直後、右クリックや［•••］で操作メニューを開くときは、選択を残したまま詳細パネルを閉じます。通常の左クリックや人物検索での候補確定で再表示できます。 詳細パネルはキャンバスの上に重ねて表示するため、パネルの開閉によって作図面の寸法、表示倍率、表示位置、図上の座標が変わることはありません。選択直後に人物をドラッグしても座標がずれることなく操作できます。

画面幅900px以下では、詳細パネルは作図面の下に表示されます。項目が収まらないときは、パネルの中を上下にスクロールしてください。

選択パネルを閉じるには、パネル見出し右上の閉じるボタン（[×]）を押すか、作図面の空白部分をクリックします。 閉じるボタンを押したときは、入力中の変更を確定して保護したうえで作図面へキーボードの操作対象を戻し、選択を解除してパネルを閉じます。 作図面の空白部分をクリックした場合も入力内容の確定保護を試みたうえで選択を解除します（入力確定に失敗した場合は選択を解除しません）。

作図面にフォーカスがある状態で Esc キーを押した場合も、選択を解除してパネルを閉じます。 入力欄の編集中や日本語入力（IME）変換中に Esc キーを押しても、人物の選択は解除しません。

人物を中央へ表示したいときは、後述の人物検索で候補を確定してください。人物の座標は変更しません。図形はクリックして選択します。

人物を 1 人選択
氏名、性別、続柄などの入力欄が表示されます。 入力値は IME 確定後や入力変更時に自動で反映されます。 詳細モードでは住所や生年月日、業務設定などもあわせて表示されます。
図形・注釈を 1 件選択
表示テキスト、文字サイズ、線の太さ、幅や高さ（サイズ）に加え、文字色・線の色・背景色を左側プロパティ欄で直接編集できます。 文字色、線の色、背景色は厳選された8色の丸型サンプル色（黒、白、グレー、紫、青、赤、緑、オレンジ）から選択できます。 テキストの背景には「標準色」（薄い黄、#fffceb）もあり、白や透明から初期背景へ戻せます。 入力値は自動で反映されます（文字は IME 確定時、数値は変更確定時に反映）。 テキストボックスは背景を透明にしても面全体がつかみやすく、ホバー時に薄い枠線ガイドが表示されます。 吸着矢印の幅・高さを変更すると、表示位置を保ったまま人物への吸着を解除します。 重なり順（最前面、最背面、人物の前面、人物の背面）の切り替えや削除も行えます。
複数選択
複数選択時は「3 人を選択中」「2 個の図形・注釈を選択中」のように選択件数が表示されます。 人物を複数選択しているときは「選択した人物を整列」ボタンが表示されます。 図形を複数選択しているときは左揃え、上揃え、横・縦の均等配置、一括削除ボタンが表示されます。 選択状態を解除するには、キャンバスの空白部分をクリックするか、Esc キーを押します。

人物の矩形選択

操作 動作
背景をドラッグ 表示範囲を移動します。
Shift + 背景ドラッグ 矩形と交差する人物をまとめて選択します。
Ctrl + Shift + 背景ドラッグ 既存の人物選択へ追加します。

矩形選択の対象は人物ノードだけで、図形・注釈は含まれません。 選択後に 1 人をドラッグすると、選択中の人物をまとめて移動できます。

人物の検索

登録済みのすべての人物を対象に、氏名、続柄、ID で絞り込み検索を行えます。

ツールバーの検索窓をクリックするか、ショートカットキー Ctrl + K（Mac では Command + K）を押すと、検索入力欄にフォーカスします。 文字を入力すると候補一覧がポップアップ表示され、各候補には「氏名 ＋ 続柄 ＋ ID」が表示されます。

検索窓に入力している間は、作図面の表示位置、表示倍率、操作履歴（Undo・Redo）、図のデータモデルは一切変更されません。 上下矢印キーで候補を選び、Enter キーを押すか、候補をクリックして確定したときのみ、該当する人物を選択して作図面の中央へ移動し、詳細パネルを開きます。

日本語入力（IME）の変換中に Enter キーを押しても、候補の確定や画面移動は行われません。 入力欄を空にすると候補ポップアップは閉じます。 また、候補一覧の外側をクリックするか、Tab キーまたは Esc キーを押しても閉じます。 候補一覧のテキストは安全に描画され、不正なスクリプトの混入を防止します。

応用の使い方

配置と図形

表示操作はキャンバス右上のフローティングボタンにまとめています。 縮小・拡大ボタンの間に現在の倍率を表示します。倍率をクリックすると初期表示へ戻り、右の「全体表示」で図全体を表示できます。 「図を原点付近へ移動」は「整列」メニューから実行します。人物を中央に表示するには、人物検索で候補を確定します。 選択状態は、パネル右上の閉じるボタンを押すか、作図面の空白部分をクリックするか、あるいは作図面にフォーカスがある状態で Esc キーを押すと解除できます（入力欄編集中や IME 変換中には解除しません）。 「関係」「整列」「一括操作」「保存 / 復元」などのメニューは、メニューの外側をクリックしたとき、別のメニューを開いたとき、メニュー内の項目を選択したとき、または Esc キーを押したときに閉じます。 「元に戻す」「やり直し」はツールバーの矢印ボタンで操作できます。 作図領域は大画面でも幅を制限せず、未選択時は画面領域全体を使って表示します。選択時は desktop 環境では左側に幅 340 px の詳細パネルがオーバーレイ表示され、開閉しても図の座標・倍率・表示位置は変わりません。

選択人物の家族を整列
選択した人物が所属するfamilyを整列します。親・配偶者を同じ行へ、 子をその下へ配置します。複数のfamilyに所属する場合は親側のfamilyを 優先します。人物付近の図形・注釈も可能な範囲で追従し、整列後は 「元に戻す」「やり直す」で位置を戻したりやり直したりできます。
選択した人物を整列
2人以上を選択して実行すると、選択中の人物だけを選択範囲に含まれる 関係に沿って整列します。未選択の人物は移動しません。選択範囲の 左上を基準に配置し、人物付近の図形・注釈も可能な範囲で追従します。 整列後は「元に戻す」「やり直す」で位置を戻したりやり直したりできます。
全体を自動整列
親子関係から世代を算出し、原点付近を基準に世代ごとに配置します。 配偶者を可能な範囲で隣接させ、同じ家族グループ（family）に登録された子をまとめます。 家族グループ間に間隔を取り、家族関係が未設定の人物は登録済みの人物の下へ配置します。 整列前の座標に依存せず、同じ関係データには同じ配置を計算します。 人物付近の図形・注釈は可能な範囲で追従します。整列後は 「元に戻す」「やり直す」で位置を戻したりやり直したりできます。
図を原点付近へ移動
相対配置を保ったまま、図全体を原点付近へ平行移動します。 並べ直す機能ではありません。図がマイナス座標や原点から離れた位置に あるときに使用します。

図形・注釈

  • テキストはツールバーから、四角、丸、×印、矢印は「図形」メニューから追加します。狭い画面で操作が見つからない場合は、折り返したツールバーも確認してください。「丸」は真円と楕円の両方を描けます。
  • テキストは配置位置をクリックすると空のボックスを1つ登録し、追加モードを終了して文字入力を始めます。未入力で編集を終えてもボックスは残ります。入力中の Esc は文字の変更だけを取り消し、ボックスは削除しません。追加自体を取り消す場合は「元に戻す」を使います。
  • 四角、丸、×印、矢印はクリックまたはドラッグで1つ配置すると追加モードが終了し、その図形を選択したままプロパティを開きます。続けて追加する場合はツールをもう一度選びます。配置中の Esc は追加を中止します。人物の連続配置は従来どおりです。
  • ツール選択後は半透明の配置プレビューで位置や形状を確認できます。プレビューは保存データ、印刷、SVG 出力には含まれません。
  • Shift を押しながらドラッグすると、形状や方向を固定できます。
  • 文字色、線の色、背景色は8色の丸型サンプル色から選べ、テキスト背景には「標準色」（#fffceb）も用意しています。透明背景のテキストボックスも面全体をクリック・ドラッグで選択できます。線の太さ、文字サイズ、幅や高さを変更した場合も自動で反映されます。
  • 四角と丸は背景が透明でも内側から選択・ドラッグできます。×印と矢印には、見える線を太くせずに線の周囲14pxの操作領域を設けています。ポインターを重ねると操作対象が強調されます。この透明な操作領域は画像・SVG出力や印刷に含めません。
  • 透明な四角と丸の内側で関係線にポインターを重ねると、図形より関係線の選択・強調を優先します。線のない位置や図形の枠線からは、引き続き図形を選択・ドラッグできます。不透明な図形の裏の線は選択しません。
  • 複数選択して、左揃え・上揃え・横や縦の均等配置ができます。
  • 人物と重なる注釈は Alt（Mac では Option）を押しながらクリック・ドラッグ・右クリックします。テキストは同じキーを押しながらダブルクリックすると再編集できます。
  • 図形は左側プロパティ欄や右クリックメニューで人物の前面・背面を切り替えられます。テキストは常に人物の前面のため、この2つの操作はグレーアウトします。「1段前面／背面」は同じ側の図形・注釈同士の重なり順を変更します。
  • 矢印の端点を人物の近くへ移動すると、上・右・下・左のいずれかへ吸着します。吸着した矢印は人物の移動に追従します。
  • 人物を削除した場合は、矢印は現在の座標を保ったまま吸着だけが解除されます。
図形のコピーについて

図形のコピー・貼り付けはアプリ内のメモリだけで行い、 OSのクリップボードへは送信しません。 ページを閉じるとコピー内容は失われます。

保存と復元

JSON保存

上部ツールバーの「保存 / 復元」メニューから「保存」を選ぶと、人物情報、family 情報、図形・注釈、選択状態、表示倍率、表示位置をファイル（JSON 形式）として保存します。 「ファイルを読み込む」を選ぶと、保存したファイルを読み込んで図を復元できます。

JSON復元

  • 復元すると、現在の画面の内容は置き換えられます。
  • 復元前の状態は、操作履歴が残っていれば「元に戻す」で戻せます。
  • 本ツールが出力したJSONファイルを使用してください。出所不明のファイルは読み込まないでください。
  • 復元後は、人物・関係・図形の件数を確認してください。
  • 保存データ形式v7より前のファイルには、図形・注釈が含まれない場合があります。
  • 安全のためファイルは2 MiB以下、人物500人以下、家族1,000件以下、図形・注釈500件以下に制限します。
  • 1家族の親は2人まで、親子・配偶者参照は合計5,000件以下です（familyのない旧形式では人物側の親・配偶者参照が1,000件以下）。
  • familyを使用する形式では、養子縁組などで複数の家族に属する人物の親参照も受け付けます（親・配偶者は各最大500人、参照全体は5,000件以下）。
  • 文字列は人物情報2,000文字・注釈文4,000文字・全体メモ10,000文字以内、IDは64文字以内です。注釈テキストは1件100行以下・全注釈で合計5,000行以下です。参照先・座標・色指定なども検証します。
  • JSON保存では復元可能性とUTF-8換算2 MiBの容量を検証し、必要ならコンパクトな形式への切替を試みます。
  • 図形・注釈の入力は確定時に文字数・行数を確認します。
  • 旧自動保存データが残っている場合のみ、退避・削除の操作を表示します。
  • 不正または上限超過のJSONは読み込まず、現在編集中のデータを維持します。

未保存の変更がある場合

人物・関係・図形・注釈・全体メモに未保存の変更がある場合のみ、 タブを閉じる・再読込み・ページ移動時にEdge標準の確認画面が表示されます。 選択や表示倍率だけを変えた場合は表示されません。 Undoで保存済みの内容に戻ると警告は解除されます。

自動保存はありません。Edge の強制終了や PC の電源断では警告できないため、 編集中は「保存 / 復元」メニューの「保存」でファイルへ保存してください。 通常ダウンロードの場合は保存先のファイルを確認してから保存完了を回答してください。

旧自動保存データからの移行

旧版の保存データが残る場合のみ「旧データを復元」「旧データを削除」を表示します。 必要なら復元してJSONファイルに保存した後で旧データを削除してください。 自動的に削除することはありません。

出力と印刷

PNG・SVG出力

上部ツールバーの「保存 / 復元」メニューから「画像として出力（PNG）」を選ぶと、現在の図を余白付きの高解像度 PNG 画像として保存します。文書への貼り付けや資料作成に適しています。 「SVG 形式で出力」を選ぶと、拡大しても劣化しないベクター画像（SVG ファイル）として出力できます。 画像出力および印刷には、現在の利用モード（簡易モード／詳細モード）のカード表示が反映されます。 いずれの画像出力および印刷でも、選択枠、操作ハンドル、作成中のプレビューレイヤーに加え、人物カード右上の［•••］ボタンは除外されます。

出力時には、script 要素、foreignObject、iframe、object、embed、 audio、video 要素、on で始まるイベント属性、外部への参照を取り除きます。 同一 SVG 内の ID 参照と data:image 形式の画像参照だけを残します。

印刷と印刷プレビュー

上部ツールバーの「印刷」ボタンを押すと、印刷設定・プレビューモーダルが開きます。 用紙は A4 の縦／横、印刷範囲は「図全体」／「現在の表示範囲」から選べます。 「用紙の向き＋印刷する範囲」「倍率＋余白」を横並びで設定できます。用紙プレビューは縦横とも表示領域に合わせて縮小し、用紙内をスクロールせず確認できます。 印刷プレビューと実印刷で同一の印刷用要素を使用するため、プレビューを表示しても作図面の表示位置や倍率は変化しません。 内容を確認のうえ「印刷する」を押すと、ブラウザーの印刷画面が開きます。 ブラウザーやプリンター側で用紙・向き・余白を変えると、縮尺や改ページが変わる場合があります。最終の印刷画面でも全図が収まることを確認してください。

設定項目 内容
印刷タイトル 用紙左上に印字するタイトルを指定します（初期値：「相続関係図」）。
用紙の向き A4 の横（初期値）または縦を選択します。
印刷する範囲 「図全体」（初期値）または、現在のパン・ズームで見えている「現在の表示範囲」を選択します。
倍率（%） 対象範囲が用紙に収まる状態を100%として、10～400%の整数で指定します。100%を超えると一部が用紙外になる場合があります。
余白（mm） 用紙の余白を数値で指定します（初期値：8 mm）。
凡例を表示する 用紙下部に性別や死亡等の凡例を表示するかどうかを指定します（初期値：無効）。

印刷時は編集メニュー、ツールバー、右クリックメニューを隠し、 左上にタイトル、右上に作成日（YYYY年MM月DD日形式）、図、および指定に応じた凡例を出力します。 対象者名やメモ欄等の個別入力項目はありません。 背景色を印刷するには、ブラウザーの印刷設定で「背景のグラフィック」を有効にする必要があります。

よくある質問

法定相続分は自動で計算されますか？

計算されません。本ツールは関係を図として整理するためのもので、 法定相続人、相続順位、法定相続分を確定する機能はありません。 入力した業務情報も、法的・行政的な確定を意味するものではありません。

図が画面に見当たりません。

人物や図形はマイナス座標へも移動できるため、表示範囲の外に出ている 可能性があります。「全体表示」や人物検索での候補確定、または 「図を原点付近へ移動」を使用してください。

全体自動整列の結果が思ったとおりになりません。

複雑な再婚、養子縁組、複数のfamilyがある場合は、規則どおりの配置が 業務上の見え方と一致しないことがあります。整列後に手動で調整してください。 図形・注釈の追従は整列前の最寄り人物から推定するため、 意図した人物に付いてこないことがあります。

保存し忘れて閉じそうになった場合は？

未保存の実データ変更がある場合はEdgeの標準確認画面が出ます。 強制終了・電源断では機能しないため、こまめにJSONファイルへ保存してください。

ブラウザが突然終了した場合は復元できますか？

できません。自動保存は行っておらず、ページ離脱警告も強制終了には対応しません。 必要な内容はこまめにJSONファイルへ保存してください。

SVGを他のソフトで開くと見た目が変わります。

SVG内の文字表示は閲覧環境のフォントに依存し、矢印の先端も 閲覧ソフトによって表示差が生じます。配布前に、実際に使うソフトで 表示を確認してください。

その他

利用上の注意

  • 法定相続人、法定相続分、代襲相続、数次相続を自動で判定する機能はありません。
  • 続柄の自動設定は図の登録関係に基づく編集候補です。婚姻状態、出生順、養子縁組の法的種別は自動確定しません。
  • 夫婦線のない親2人の関係登録（Issue #258）は未実装です（現行データモデルでは親2人を指定すると親間に夫婦線が生成されます）。
  • 戸籍情報との照合、相続放棄の効力の確認は行いません。
  • 関係チェックの結果だけで法的な判断を確定しないでください。
  • 印刷物の縮尺や法的様式への適合を保証しません。
  • 人物カード右上の［•••］ボタンは作図用の補助表示であり、画像出力や印刷出力には含まれません。
  • SVG内の文字表示は、閲覧環境のフォントに依存します。矢印の先端は閲覧ソフトによって表示差が出ることがあります。
  • 全体・家族・選択人物の整列は、複雑な再婚、養子縁組、複数familyでは意図どおりにならない場合があります。整列後の手動調整が必要になることがあります。
  • 整列時の図形・注釈追従は、整列前の最寄り人物などから推定するため、意図した人物に追従しないことがあります。
  • 図形・注釈と人物やfamilyを明示的に関連付ける機能はありません。
  • 矩形選択は、選択矩形と一部でも交差する人物を対象とします。
  • 人物と図形・注釈は、マイナス座標へも移動できます。図が表示範囲の外にある場合は「全体表示」、人物検索での候補確定、「図を原点付近へ移動」を使用してください。
  • 未保存警告はEdgeの強制終了・PCの電源断には対応できません。
  • 作図面での人物・関係線・図形の直接操作には、マウスまたはタッチ操作が必要な機能があります。キーボードだけでは全ての作図操作を完結できません。
  • タッチとペンの複数入力では、操作が競合する可能性があります。
  • 開発環境における人手による Microsoft Edge での受入検証は未実施です。本番環境の Edge で動作確認してください。

セキュリティとプライバシー

データはブラウザ内で処理します

サーバーへのアップロード、外部APIへの送信、外部クラウドへの保存、 外部CDNやWebフォントの利用はありません。 図形データをOSのクリップボードへ送信することもありません。

ただし、次の場所にはデータが残る可能性があります。

  • JSONファイルの保存先
  • PNG・SVGファイルの保存先
  • ブラウザのダウンロード履歴
  • 旧版の自動保存領域（移行・削除まで）
  • ブラウザまたはOSの一時領域
  • 印刷データおよびプリンターの履歴
  • PDFとして保存した場合の保存先
JSON・画像・印刷物に含まれる個人情報に注意してください

氏名、住所、生年月日、親族関係、相続放棄状況、共有持分などが そのまま含まれます。JSONを保存するときは旧JSONの備考も保持されます。 保存先、共有先、メール添付、外部媒体への保存に注意してください。 簡易モードで見えていない詳細情報もJSONには保存されます。JSONを共有するときは、表示中の図だけで判断しないでください。PNG・SVGや印刷物を庁外へ提供する場合も、出力内容を確認してください。

不要になったJSON、SVG、PDF、印刷物は、所属組織の情報セキュリティポリシー、 個人情報保護規程、文書管理規程に従って管理・廃棄してください。
