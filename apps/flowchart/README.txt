お役立ちアプリBOX / フロー図メーカー  v1.2.5
====================================

現在の共通assets版: v2.1.0。本ツールは公開前レビューの投稿メニュー修正によりv1.2.5に更新しています。
過去の変更履歴に記載された共通assets版は当時の記録です。

■ 1. 概要


● 概要

本ツールは、Excalidrawを利用してフロー図、業務手順図、
システム構成図等をブラウザ上で作成するための庁内向け静的Webアプリです。

IISからHTML、CSS、JavaScript、フォント等の静的ファイルを配信して
動作します。

本パッケージは、外部CDN、外部API、クラウド共有および共同編集機能を
使用しない構成としています。

注意:
外部通信を技術的に禁止するには、アプリ側の設定だけでなく、
IISのContent-Security-Policyおよびネットワーク側の通信制御が必要です。

● 主な用途

- 業務フローの作成
- 申請、受付、審査等の手続き図の作成
- システム構成図の作成
- 庁内ネットワーク構成の整理
- 会議、説明資料用の簡易図面作成
- Mermaid記法を利用した図の作成
- サンプル図を基にした図面作成


■ 2. 動作環境


サーバー:
- Windows Server
- IIS

クライアント:
- Microsoft Edge

本番配置前に、実際に庁内で使用するMicrosoft Edgeのバージョンで
動作確認してください。

画面表示については、通常倍率だけでなく、125%、150%、200%等でも、
ボタンやタイトルが重ならないことを確認してください。


■ 3. 構成ファイル


- index.html: Excalidrawを起動する画面
- asset-path.js: 同梱アセットの参照先設定
- flow-app.css / samples.css: アプリ固有のスタイル
- notice.js / samples.js: 通知およびサンプル図
- assets/: Excalidraw本体、フォント等の同梱アセット
- licenses/: 第三者ライセンス
- help.html / web.config: 利用者向けヘルプおよびIIS設定


■ 4. 配置・初期設定


本フォルダー一式を、IISの「お役立ちアプリBOX」のapps配下へ配置してください。

配置例:

  appbox/
    index.html
    assets/
      appbox-tokens.css
      appbox-themes.css
      appbox-base.css
      appbox-chrome.css
      appbox-help.css
    apps/
      flowchart/
        index.html
        help.html
        asset-path.js
        notice.js
        flow-app.css
        samples.js
        samples.css
        assets/
          index-xxxxxxxx.js
          index-xxxxxxxx.css
          フォント
          画像
          Worker
          動的チャンク等

重要（assetsフォルダーが2か所あります）:
- flowchart\assets\ はExcalidrawのビルド成果物です。
- appbox\assets\ はお役立ちアプリBOX共通のアセットです。
- index.html内では、前者を「./assets/」、後者を「../../assets/」と
  記述します。取り違えると画面が表示されません。

index.htmlが読み込む共通ファイル:

- ../../assets/appbox-tokens.css
- ../../assets/appbox-themes.css
- ../../assets/appbox-base.css
- ../../assets/appbox-chrome.css

これらはflow-app.cssより前に読み込みます。
共通CSSはCSSカスケードレイヤー（@layer appbox）を使用しており、
レイヤーに属さないExcalidraw本体のCSSおよびflow-app.cssが
必要な固有調整を上書きします。Issue #84では、生成済みExcalidraw bundleを
変更せず、AppBoxの共通ヘッダー、テーマ色、作図面周辺を新標準へ合わせています。

help.htmlは、Excalidraw本体を一切読み込まない独立したページです。
共通ファイルに加えて、テーマ色の背景を適用するappbox-help-theme.cssを読み込みます。

- ../../assets/appbox-tokens.css
- ../../assets/appbox-themes.css
- ../../assets/appbox-base.css
- ../../assets/appbox-chrome.css
- ../../assets/appbox-help.css
- ../../assets/appbox-help-theme.css
- ../../assets/appbox-help.js


appbox\assets\を同時に配置しないと表示が崩れます。
本ツールだけを単独で切り出して配置することはできません。
詳細はappbox\assets\README.txtを参照してください。

利用者向けの説明はhelp.htmlです。
README.txtは管理者・保守担当者向け資料であり、
一般利用者向けのリンク先には使用しません。

注意:
- assetsフォルダー内のファイル名や構成を変更しないでください。
- index.htmlが参照するファイル名と、実際のファイル名を一致させてください。
- asset-path.jsは、Excalidraw本体のJavaScriptより先に読み込んでください。
- notice.jsは、通知を利用するJavaScriptより先に読み込んでください。
- flow-app.cssとsamples.cssは、Excalidraw本体のCSSより後に
  読み込んでください。
- 動的チャンクは、機能を初めて使用した時点で読み込まれる場合があります。
- 一部のファイルだけを差し替えると、画面が表示されない場合があります。
- 更新後に古いファイルが表示される場合は、index.html内の
  キャッシュ更新用識別子「?v=」の値を更新してください。
- ビルド済みファイルを更新した場合は、動的チャンクを含む
  assetsフォルダー全体の整合性を確認してください。


■ 5. 主な機能と仕様


● 主な機能

- Excalidrawによる図形、線、矢印、テキストの作成
- 業務資料向け初期スタイル
- Mermaid記法からの図面生成
- Mermaid内の<br>、<br/>等による改行への対応
- オブジェクトへのスナップ
- 矢印端点の図形への接続
- 矢印を接続した図形の移動への追従
- 3種類のサンプル図
- .excalidraw形式での保存および読込み
- PNG等の画像出力
- 印刷およびクリップボードへのコピー
- 外部HTTP/HTTPSリンクへの遷移の補助的な遮断
- ローカル資産を利用した閉域運用
- 日本語UIおよび日本語フォントのフォールバック
- キーボード操作時のフォーカス表示
- OSの視覚効果低減設定への対応

利用できる具体的な機能や出力形式は、同梱しているExcalidrawの
バージョンおよび本パッケージの設定によって異なります。

● 画面構成

画面は、主に次の領域で構成されます。

- AppBox共通ヘッダー（ポータル・ヘルプへの導線）
- アプリ名と、その下に続く説明・保存・読込／画像出力の案内。広幅では右側にサンプル図の選択
- Excalidrawの作図領域
- 通知表示

共通ヘッダーの導線は、アプリ本体のJavaScriptによる画面生成を
待たずに表示できるよう、index.htmlへ直接配置しています。
フッターと表示切替ボタンは設けていません。アプリアイコンの寸法と左端、
アプリ名の文字サイズを共通ヘッダーに合わせ、説明と保存・読込／画像出力の案内を
広幅では1行にし、狭幅では折り返します。
サンプル図は画面幅が900pxを超える場合だけ表示します。
作図面には共通ヘッダーを除いた画面高を割り当て、縦幅が足りない場合は
ページをスクロールして操作できます。

表示される選択肢は次の3種類です。

- 業務フロー
- システム構成図
- 申請手続き

ヘッダーとアプリ背景は、お役立ちアプリBOX内の他アプリとの統一感を考慮し、
左上をやや濃く、右および下へ向かって薄くなるグラデーションとしています。

● 業務向け初期スタイル

新規作図時およびMermaidからの作図時の初期スタイルを、
手書き風ではなく業務資料向けに設定しています。

- 線のラフさ: 0
- 線種: 実線
- 塗り: ベタ塗り
- 図形の角: シャープ
- 矢印: シャープ
- オブジェクトへのスナップ: 有効
- 矢印バインディング: 有効
- 文字: 通常表示向けフォント

矢印端を図形へ近づけると接続でき、接続後は図形を移動した場合に
矢印が追従します。

各スタイルは、Excalidrawのプロパティから図形ごとに変更できます。

既存の.excalidrawファイルを読み込んだ場合は、原則として各図形に
保存されているスタイルを維持します。

● フォント

日本語表示およびフォント一覧の使いやすさを改善しています。

対応候補として、次のフォント名を設定しています。

- BIZ UDゴシック
- BIZ UDPゴシック
- 游ゴシック
- 游ゴシック UI
- メイリオ
- MS ゴシック
- MS Pゴシック
- MS 明朝
- MS P明朝
- Segoe UI
- Arial
- Times New Roman

これらは、Windows端末にインストール済みのローカルフォントを使用します。
OS標準フォント、Microsoft提供フォント等のフォントファイルそのものを、
本パッケージへ追加しているわけではありません。

端末に選択したフォントがない場合は、設定済みのフォールバックフォントで
表示されます。

日本語文字については、文字種や端末環境に応じて代替フォントが
使用される場合があります。

互換性上の注意:
追加フォントは、本アプリ独自のフォントIDを使用します。
公式Excalidrawや本アプリ以外の環境でファイルを開いた場合は、
フォント名や見た目が一致しない可能性があります。

重要なファイルは、本アプリと同じ構成で再読込みできることを
確認してください。

● Mermaidからの作図

本ツールでは、Mermaid記法からExcalidraw図形を生成する機能を利用できます。

対応内容:
- Mermaid記法の解析
- Mermaid図からExcalidraw図形への変換
- <br>および<br/>の実改行への変換
- エスケープ済みのbr表記の実改行への変換
- 生成図形への業務向けスタイルの適用
- 生成した矢印と図形の接続
- 図形移動時の接続矢印の追従

改行修正は、解析後の文字列正規化として行います。
任意のHTMLやスクリプトの実行を許可する変更ではありません。

Mermaid本体は、securityLevel: strictおよびサニタイズ処理を維持する
構成としています。

注意:
- Mermaid機能では、必要な追加JavaScriptが初回利用時に動的に
  読み込まれる場合があります。
- ネットワーク切断状態でも、必要な動的チャンクがローカルから
  読み込まれることを確認してください。
- Mermaidの記法や変換結果は、同梱しているバージョンの仕様に依存します。
- 複雑な図や大量のノードは、変換または表示に時間がかかる場合があります。

● サンプル図

次の3種類のサンプル図を内蔵しています。

- 業務フロー
- システム構成図
- 申請手続き

サンプル図は、画面幅が900pxを超える場合にアプリ情報の右側から選択します。

既に表示中の図形がある状態でサンプルを選択すると、現在の図を
置き換える前に確認メッセージを表示します。

削除済み要素だけが存在する場合は、表示中の図があるものとして
扱わないよう判定します。

サンプルを読み込むたびに、サンプル要素のIDを一意に生成します。

読込み中は、連続操作による競合を防ぐため、サンプルボタンを
一時的に無効化します。

注意:
重要な図を編集中の場合は、サンプルを読み込む前に.excalidraw形式で
保存してください。

Excalidraw本体の状態や操作履歴によっては、サンプルへの置換後に
Undoで完全に元へ戻せない場合があります。

● 通知表示

外部リンクの遮断、サンプル読込み結果等は、共通通知関数を利用して
画面上へ表示します。

通知処理はnotice.jsに分離しています。

通知領域がまだ生成されていない時点では、通知を表示できない場合があります。
通常の利用操作では、アプリ画面の生成後に通知処理が実行されます。


■ 6. データの取扱い


● データの取扱い

本ツールは、図の編集処理をブラウザ内で実行します。

本パッケージ独自のクラウド保存、クラウド共有および共同編集機能は
使用しません。

ただし、ブラウザ内処理であっても、利用するExcalidrawの構成によっては、
編集中データや設定が次の領域へ保存される場合があります。

- localStorage
- sessionStorage
- IndexedDB
- ブラウザキャッシュ
- ダウンロードフォルダー
- クリップボード

「サーバーへ送信しない」ことと「端末にデータが残らない」ことは異なります。

個人情報、機密情報、庁内ネットワーク構成等を扱う場合は、
所属組織の情報セキュリティポリシーおよびデータ取扱規程に
従ってください。

共用端末で使用する場合は、作業終了後に次の取扱いを確認してください。

- ダウンロードファイル
- クリップボード
- ブラウザ保存領域
- 最近使用したファイル
- 印刷履歴
- 一時ファイル

● 保存・読込み・出力

Excalidraw本体が提供する機能により、構成に応じて次の操作を利用できます。

- .excalidraw形式での保存
- .excalidraw形式のファイルの読込み
- PNG等の画像出力
- クリップボードへのコピー
- 印刷
- 資料への貼付け

利用できる出力形式は、同梱しているExcalidrawのバージョンおよび
本パッケージの設定によって異なります。

庁外提供前の確認:
出力ファイルを庁外へ提供する場合は、次の情報が含まれていないか
確認してください。

- 個人情報
- 機密情報
- 庁内サーバー名
- 内部IPアドレス
- 庁内URL
- ファイルパス
- 外部リンク
- 非公開のシステム構成
- 画像に含まれる非公開情報
- 編集用データやコメント


■ 7. セキュリティとプライバシー


● 外部リンクの取扱い

本パッケージでは、外部HTTP/HTTPSリンクへの遷移を補助的に遮断します。

外部リンクが操作された場合は、画面遷移を停止し、利用者へ通知します。

同一サーバー内の相対リンクは外部リンクとして扱いません。
このため、「お役立ちBOXに戻る」ボタンは通常どおり利用できます。

次の形式は、運用設定やブラウザの仕様によって扱いが異なる場合があります。

- mailto:
- tel:
- file:
- data:
- blob:
- 独自プロトコル

図中へリンクを設定できる場合は、庁内で許可されたURLだけを
使用してください。

注意:
リンククリックとwindow.openの補助的な遮断だけで、次のような全通信を
遮断できるわけではありません。

- fetch
- XMLHttpRequest
- WebSocket
- Worker
- 外部画像
- CSSからの外部参照
- フォント通信
- 動的import

外部通信の完全な制御には、IISのContent-Security-Policyおよび
ネットワーク側の制御が必要です。

● 閉域運用

Excalidrawのフォント、JavaScript、CSS、画像、Workerおよび動的チャンク等は、
原則として本アプリ配下から読み込むよう構成しています。

本番環境では、次を確認してください。

- ネットワーク切断状態で起動できる
- JavaScriptがローカルから読み込まれる
- CSSがローカルから読み込まれる
- フォントがローカルまたは端末から読み込まれる
- Mermaid等の動的チャンクがローカルから読み込まれる
- Workerが必要な場合にローカルから読み込まれる
- 外部リンクが遮断される
- ブラウザ開発者ツール上で意図しない外部通信がない
- 保存、読込み、出力、印刷が閉域状態で利用できる

● セキュリティ上の留意事項

本パッケージでは、次の対策を維持しています。

- 外部CDNおよび外部APIを使用しない構成
- 外部HTTP/HTTPSリンクの補助的な遮断
- MermaidのsecurityLevel: strict
- Mermaid入力および生成内容のサニタイズ
- ローカル資産参照
- IISのContent-Security-Policyを前提とした閉域運用
- 通知処理の共通化
- サンプルUIをDOM APIで生成
- サンプル要素IDの一意化

ただし、アプリ単体で外部通信、端末保存、利用者のコピー操作、
出力ファイルの持出し等を完全に制御することはできません。

所属組織の情報セキュリティポリシー、端末運用基準および
データ取扱規程に従ってください。


■ 8. アクセシビリティと操作性


次の対応を行っています。

- サンプル選択ボタンを通常のbutton要素として生成
- サンプル選択肢を操作グループとして定義
- キーボード操作時のフォーカス枠
- 戻るボタンへの分かりやすいaria-label
- 装飾用SVGを読み上げ対象から除外
- 通知領域へのrole="status"
- 通知領域へのaria-live="polite"
- 読込み中のサンプルボタンへのaria-busy
- OSの視覚効果低減設定への対応
- 狭い画面で戻るボタンの文字が非表示になっても、
  アクセシブルな名称を維持

Excalidraw本体のアクセシビリティ対応範囲は、同梱バージョンの
仕様に依存します。

本番確認では、次を確認してください。

- Tabキーで各操作へ移動できる
- EnterまたはSpaceキーでボタンを操作できる
- フォーカス位置を視認できる
- 200%表示でも操作できる
- 通知内容が支援技術で認識できる


■ 9. 既知の制約


- クラウド共有および共同編集機能は使用できません。
- 外部CDNやオンライン素材を前提とする機能は利用できません。
- 外部通信の完全な遮断には、IISおよびネットワーク側の設定が必要です。
- サンプルの一部の矢印は、図形を移動しても追従しない場合があります。
- Mermaidから生成した矢印の追従可否は、変換結果と接続状態に依存します。
- サンプル図形の互換性は、同梱したExcalidrawのバージョンに依存します。
- 独自フォントIDは、公式Excalidraw等で同じ見た目にならない場合があります。
- 端末に指定フォントがない場合は、代替フォントで表示されます。
- サンプルへの置換後、Undoで完全に元の図へ戻れない場合があります。
- 大きな画像や複雑な図は、端末性能によって動作が遅くなる場合があります。
- 通知領域が生成される前に通知が発生した場合、通知が表示されないことが
  あります。
- ビルド済みJavaScriptが生成するDOM構造が変わると、ヘッダーや
  サンプル表示の追加処理が動作しなくなる場合があります。
- Excalidraw本体を更新した場合は、サンプル表示、Mermaid、フォント、
  保存、再読込み等の回帰試験が必要です。


■ 10. 運用・保守


● IIS設定上の推奨事項

HTML内のmeta要素だけでなく、IIS側でも適切なHTTPレスポンスヘッダーを
設定してください。

推奨する主な設定:
- Cache-Control
- Content-Security-Policy
- X-Content-Type-Options: nosniff
- Referrer-Policy: no-referrer
- frame-ancestors 'none'
- X-Frame-Options: DENY
- Permissions-Policy

Content-Security-Policy:

index.htmlのmeta CSPによりGitHub Pagesでも外部オリジンを許可しません。
IISのweb.configにも同じ制約を設定し、frame-ancestorsを追加しています。

  default-src 'self';
  script-src 'self' 'wasm-unsafe-eval';
  style-src 'self' 'unsafe-inline';
  img-src 'self' blob: data:;
  font-src 'self' data:;
  worker-src 'self' blob:;
  connect-src 'self' blob: data:;
  object-src 'none';
  frame-src 'none';
  media-src 'none';
  base-uri 'none';
  form-action 'none'

script-srcのwasm-unsafe-evalは画像出力時の同梱フォント処理に必要です。
JavaScriptのunsafe-evalは許可しません。connect-srcは同一サイト内の
フォント読込みとdata/blobのみを許可します。asset-path.jsのfetch制御も
同一サイトのGET/HEADとローカルデータに限定し、POSTとリダイレクトを拒否します。
ライブラリの外部公開メニューはCSSで非表示にします。React管理のDOMは削除しません。生成bundle自体は変更しません。

既知の制約（SVG出力）:
現行CSPを維持し、JavaScriptのunsafe-evalは許可しない方針です。
同梱のsubset-shared chunkにはEmscripten由来のnew Functionがあり、
wasm-unsafe-evalだけではこのJavaScript生成を許可できません。
そのためフォントのサブセット化に失敗し、元のフォントファイルを埋め込む
フォールバックが動作します。SVGの見た目が正常でも数百KB〜数MBになる場合があります。
日本語・手書き書体など、使用するフォントや文字数で容量が変わります。
共有先の容量制限を確認し、大きすぎる場合はPNG出力を利用してください。
編集用データは.excalidraw形式で保存してください。
Consoleにはこの処理に由来するevalのCSP違反が出る場合があります。
これは既知の制約であり、他のCSP違反や外部通信エラーを無視する理由にはしません。

注意:
Excalidrawが次の機能を使用する場合があります。

- Blob URL
- Data URL
- Worker
- ローカルフォント
- 画像貼付け
- クリップボード
- 動的import

Content-Security-Policy設定後は、保存、読込み、画像貼付け、画像出力、
クリップボード、Mermaid変換、印刷等を実機で確認してください。

● キャッシュと更新

HTMLにはキャッシュ抑制用のmeta要素を設定していますが、
HTTPキャッシュの制御はIIS側でも実施してください。

CSSまたはJavaScriptを変更した場合は、index.htmlの参照URLに付けた
「?v=」の値を更新してください。

  <script src="./notice.js?v=1.2.4"></script>
  <script src="./asset-path.js?v=1.2.4"></script>

  <link rel="stylesheet" href="./flow-app.css?v=1.2.3-4" />
  <link rel="stylesheet" href="./samples.css?v=1.2.3-3" />

  <script src="./samples.js?v=1.2.1" defer></script>

更新してください。
