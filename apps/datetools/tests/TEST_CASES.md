# 日付ツールの確認項目

自動テストはNode.jsの標準機能だけで実行できます。新しい依存関係はありません。

```console
node tests/run-tests.cjs
```

UI状態遷移は最小DOMによる自動テストです。実ブラウザの描画・操作確認ではありません。
検索関連は互換性のため残した計算コアの試験のみで、画面の検索UIは削除しています。

## Edge / IISでの受入確認（実機で未実施）

実際の住民情報を使わず、上記の架空の日付で確認してください。

- [ ] トップページの検索で「早見表」「年齢」「和暦」「生年月日」から入口を見つけ、開ける。
- [ ] 初回表示は「早見表」タブ。基準年・本日・年齢の注記が表示される。
- [ ] 「早見表」と「生年月日から年齢計算」の2つのタブが正しく切り替わり、ヘルプが開ける。

- [ ] ヘルプの「< アプリに戻る」で本体へ戻れる。目次クリックとスクロールで対象項目が強調され、狭幅でも本文や操作を覆わない。
- [ ] 広い画面では0〜34歳・35〜69歳・70〜100歳の3組が必要以上に横へ伸びず中央寄せになり、狭い画面では2組・1組へ切り替わる。全101行に重複・欠落がない。
- [ ] 従来より狭い横幅でも2組・3組表示を維持でき、各表を上から下、左から右へ読むと年齢順になる。
- [ ] 西暦・和暦・年齢が近接し、文字の折返し・欠け・重なりがない。「100歳」も1行で読める。
- [ ] 年齢列は西暦・和暦と同じ行背景のまま青系太字で強調され、ゼブラ表示の規則性を崩していない。

- [ ] 検索欄・解除ボタン・検索件数がなく、0〜100歳の一覧性と行の密度が維持される。
