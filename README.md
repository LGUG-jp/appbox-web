# お役立ちアプリBOX Web版

LGUGのお役立ちアプリBOXを、ブラウザですぐ使える形で公開するためのリポジトリです。

このリポジトリには、`LGUG-jp/appbox` のうち、外部公開可能なアプリのみを同期して掲載します。

## 活動の位置付け

お役立ちアプリBOXは、自治体職員等の有志による非公式の技術コミュニティ **[LGUG（Local Government Underground）](https://github.com/LGUG-jp)** の自主的な学習・試作・共同開発から育てられたOSSプロジェクトです。特定の自治体の公式事業や公式提供製品ではありません。

自治体をはじめとするさまざまな現場での利用・再利用を歓迎しますが、業務への導入・運用判断は各利用組織が担います。コミュニティの活動趣旨と共同開発の共通方針は、[LGUG Organizationプロフィール](https://github.com/LGUG-jp) を参照してください。

## 公開方針

- 公開対象は事前に選定
- 公開対象アプリのみ自動同期
- 庁内専用機能やサーバ処理が必要なアプリは対象外

## 不具合・ご要望・ご質問

[Issueの投稿画面](https://github.com/LGUG-jp/appbox-web/issues/new/choose)から、不具合やアイデア、使い方の質問をお寄せください。短い説明だけでも大丈夫です。

3つのフォームから選ぶほか、自由形式（Blank issue）でも投稿できます。投稿にはGitHubへのログインが必要です。
